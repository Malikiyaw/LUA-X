Not showing? Check the three most common causes 1. The file must be exactly LUA-X.lua. A saved copy often ends up as LUA-X.lua.txt (or LUA-X (1).lua) — Studio ignores those. Enable View → File name extensions in File Explorer and rename it. 2. It must be directly inside the Plugins folder, not inside a subfolder or ZIP. Paste the path %LOCALAPPDATA%\Roblox\Plugins into File Explorer to verify. 3. If it still doesn't appear after a full Studio restart, delete the file, download again, and try once more.

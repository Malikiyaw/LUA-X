FIRST RUN

Connect LUA-X to native Roblox Studio MCP

Roblox Studio hosts the MCP server locally. LUA-X's local agent is the MCP client that connects the web workspace to your open Studio session.

  1. Open Roblox Studio and a place.
  2. Open Assistant → … → Manage MCP Servers.
  3. Turn on Enable Studio as MCP server.
  4. From this repo, run npm run build --workspace=@lua-x/desktop-bridge, then start the local agent with node apps/desktop-bridge/dist/index.js.
  5. Return here and click Connect Studio.
